# آپارات بهینه شده

ویدئوی آپارات را به سایتت اضافه کن، بدون اینکه پلیرش از همان اول صفحه را سنگین کند. افزونه اول یک پوستر محلی با دکمه دایره‌ای Play نشان می‌دهد؛ ویدئو با کلیک کاربر بارگذاری و پخش می‌شود.

هم **بلوک گوتنبرگ (ویرایشگر وردپرس)** دارد و هم **ویجت المنتور**. لینک را وارد کن؛ عنوان و پوستر خودکار آماده می‌شوند.

## چه لینکی وارد کنم؟

لینک باید یکی از این دو شکل را داشته باشد:

- `https://www.aparat.com/embed/ytf50k5` — فرمت جدیدتر و پیشنهادی
- `https://www.aparat.com/v/ytf50k5`

به‌جای `ytf50k5` شناسه ویدئوی خودت را بگذار.

## نصب و استفاده

1. [ZIP افزونه](https://github.com/ishadmehri/lightweight-player-for-aparat/releases/latest) را دانلود و از «افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه» نصب و فعال کن.
2. بلوک یا ویجت «آپارات بهینه شده» را اضافه کن و لینک را وارد کن.
3. نوشته را ذخیره کن تا پوستر در رسانه‌های وردپرس آماده شود.

می‌توانی پوستر دلخواه، نسبت تصویر، زمان شروع و پخش بی‌صدا را تنظیم کنی. گزینه «پوستر در ابتدای صفحه است» را فقط وقتی روشن کن که تصویر بدون اسکرول دیده می‌شود. المنتور برای استفاده از بلوک یا شورت‌کد لازم نیست.

## چرا سبک‌تر است؟

پوستر از سایت خودت می‌آید. پلیر پیش‌فرض، پلیر مرورگر است؛ iframe و JavaScript پلیر آپارات دانلود نمی‌شوند. قبل از کلیک هم فایل ویدئو درخواست نمی‌شود. اسکریپت کوچک افزونه فقط در صفحه دارای ویدئو بارگذاری می‌شود و از Delay JS راکت و Perfmatters مستثناست.

پلیر مرورگر پخش را با همان کلیک اول درخواست می‌کند. پخش به دسترسی API و CDN آپارات و قوانین مرورگر وابسته است؛ پلیر رسمی آپارات که اختیاری است ممکن است کلیک دوم بخواهد.

## شورت‌کد

```text
[lwpa_aparat url="https://www.aparat.com/embed/ytf50k5" start_time="65" muted="true"]
```

برای تزریق ویدئو از PHP هم می‌توانی خروجی `lwpa_render($aparat_url, $args)` را وارد مقاله کنی.

بعد از آپدیت، کش صفحه و CDN را پاک کن. اگر کش مستقل REST یا CDN داری، اکشن `lwpa_aparat_stream` در `admin-ajax.php` و مسیر `/wp-json/lightweight-player/v1/stream/*` را از کش خارج کن. برای آماده شدن پوسترهای پس‌زمینه، WP-Cron باید اجرا شود.
